# Simulation-Driven Framework for Multi-Gateway Placement Optimization in LoRaWAN Networks

## Master's Project

This repository contains the implementation of the **Simulation-Driven Framework for Multi-Gateway Placement Optimization in LoRaWAN Networks**.

The framework integrates **Python-based metaheuristic optimization** with **OMNeT++ simulation** to optimize and evaluate multi-gateway LoRaWAN deployments.

This README provides the basic instructions required to import, configure, run, and modify the framework.

---

## Framework Structure

The framework consists of two main components:

* **OMNeT++ / LoRaSim**: Used to simulate the LoRaWAN network and evaluate the gateway placement generated by the optimization algorithms.
* **Python**: Used to execute the optimization algorithms, manage the optimization process, communicate with the simulation, and process the resulting performance metrics.

The main Python control file is:

```text
Optimizer.py
```

### Optimizer.py

`Optimizer.py` acts as the **main optimization engine of the framework**. It controls the optimization workflow and is responsible for running the selected algorithms, managing their parameters, executing the simulations, and collecting the resulting performance measures.

The file is designed to be configurable and extensible. Users can:

* Select and run different optimization algorithms.
* Modify the optimization parameters.
* Change the number of gateways.
* Adjust the number of particles, individuals, ants, or other algorithm-specific parameters.
* Modify the number of optimization iterations.
* Change simulation-related parameters.
* Change input and output directories.
* Configure different experiment scenarios.
* Replace the implemented algorithms with other algorithms.
* Add new versions or modified implementations of the existing algorithms.

To use a different optimization algorithm, the required algorithm implementation can be imported into `Optimizer.py`, after which the corresponding configuration and execution section can be modified to call the new algorithm.

Similarly, the directory paths inside `Optimizer.py` should be updated when using the framework on a different computer or project directory.

All major experiment variables are configurable, allowing the framework to be adapted to different algorithms, algorithm versions, simulation configurations, and experimental requirements.

## Requirements

The framework requires:

* **OMNeT++ 5.2**
* **Python 3.x**
* **LoRaSim / OLoRaSim project included in this repository**
* Python packages required by the optimization scripts

The framework was developed and tested using **OMNeT++ 5.2**.

## Installation and Setup

### 1. Import the Project into OMNeT++

Import the complete project into **OMNeT++ 5.2**.

The OMNeT++ project contains the LoRaWAN simulation model used by the optimization framework.

After importing the project, make sure that the project builds successfully before running the optimization scripts.

---

### 2. Import the Python Codes

Import or copy the Python scripts into your Python environment.

The Python files contain the optimization algorithms and the main optimization controller.

The main file is:

```text
Optimizer.py
```

Make sure that the Python environment contains all required dependencies used by the optimization scripts.

---

### 3. Configure the Directories

Before running the framework, open:

```text
Optimizer.py
```

and update the directory paths according to the location of the project on your computer.

In particular, verify:

* OMNeT++ executable/project directory
* Simulation configuration directory
* Input files
* Host-position files
* Algorithm files
* Output/result directories

The paths used in the provided version of the framework correspond to the development environment and may need to be changed when running the framework on another machine.

---

## Configuring the End-Device Distribution

The spatial distribution of the end devices is configured through the LoRaWAN network model.

For a different end-device distribution, modify:

```text
LoRa.ned
```

The corresponding parameters can be adjusted to represent the desired spatial deployment of end devices.

This allows the same optimization framework to be evaluated under different deployment distributions without changing the overall optimization workflow.

---

## Configuring the Optimization Algorithms

The framework currently supports the implemented metaheuristic algorithms included in the project.

The algorithms are controlled through:

```text
Optimizer.py
```

The configuration can be modified to run different algorithms or different versions of an algorithm.

For example, a user can replace an existing implementation with a modified implementation by:

1. Adding/importing the new algorithm Python file.
2. Updating the import statement in `Optimizer.py`.
3. Updating the corresponding algorithm call.
4. Adjusting the algorithm-specific parameters.
5. Updating the input/output directories if necessary.

The framework does not require the overall simulation workflow to be redesigned when replacing an optimization algorithm, provided that the new algorithm follows the expected input/output structure.

## Running the Framework

The general workflow is:

```text
End-Device Distribution
        |
        v
    LoRa.ned
        |
        v
   OMNeT++ Model
        |
        v
   Optimizer.py
        |
        +----------------+
        |                |
        v                v
      GA              ACOR
        |                |
        +--------+-------+
                 |
            PSO / SA / Other Algorithms
                 |
                 v
        Gateway Placement
                 |
                 v
          OMNeT++ Simulation
                 |
                 v
       Performance Metrics
                 |
                 v
          Results / Analysis
```

In general:

1. Configure the LoRaWAN simulation in OMNeT++.
2. Configure the end-device distribution in `LoRa.ned`.
3. Open `Optimizer.py`.
4. Configure the desired optimization algorithm and parameters.
5. Update the required directory paths.
6. Configure the desired number of gateways and optimization iterations.
7. Run `Optimizer.py`.
8. The optimizer generates candidate gateway placements.
9. The generated placements are evaluated through the OMNeT++ simulation.
10. The simulation results are returned to the optimization process.
11. The optimizer continues until the configured optimization process is completed.
12. The resulting performance metrics and optimization results are saved in the configured output directory.

## Extending the Framework

One of the main purposes of the framework is to provide an extensible environment for evaluating gateway placement algorithms.

A new optimization algorithm can be incorporated by adding its Python implementation and connecting it to `Optimizer.py`.

The existing framework structure can therefore be reused while changing only the algorithm-specific implementation and configuration.

This allows researchers to use the framework to compare:

* Existing metaheuristic algorithms
* Modified versions of existing algorithms
* New metaheuristic algorithms
* Hybrid optimization algorithms
* Other optimization approaches compatible with the framework

The same OMNeT++ simulation environment and performance evaluation process can then be used to provide a consistent basis for comparison.

## Notes

* The framework was developed and tested with **OMNeT++ 5.2**.
* Directory paths in the Python scripts should be updated before running the framework on another system.
* Changes to the OMNeT++ model may require corresponding changes to the Python optimization configuration.
* Algorithm-specific parameters should be adjusted according to the implementation being used.
* The framework is intended to provide a common simulation and evaluation environment rather than restrict users to a specific optimization algorithm.
